# To-Do List App

A simple and responsive To-Do List web application built using **HTML, CSS, and JavaScript**. It helps users organize daily tasks, track completed activities, and save their tasks using browser local storage.

## Features

- **Add Tasks:** Create new tasks easily.
- **Complete Tasks:** Mark tasks as completed using checkboxes.
- **Delete Tasks:** Remove individual tasks.
- **Prevent Empty Tasks:** Prevents adding tasks without text.
- **Local Storage:** Saves tasks in the browser, so they remain available after refreshing the page.
- **Responsive Design:** Simple interface for desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
